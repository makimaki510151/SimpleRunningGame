# ポヨラン

ひとりでに走る、ジャンプだけの2Dランゲームです。ビルドはいりません。このフォルダをそのまま GitHub Pages に置けます。

## あそびかた

- ポヨは自動で右へ走ります。操作はジャンプだけです。
- スペース、クリック、タップでジャンプします。Z や ↑ でも跳べます。
- ボタンを押しているあいだは高く上がります。はなすと、その時点の高さで落ちていきます。タップだけだと小さなジャンプです。
- 動いている足場のいきおいは、ジャンプしたあとも少し残ります。上がっている足場で跳ぶと、さらに高くなります。
- 前のステージをクリアすると、次のステージが開きます。記録はこのブラウザに残ります。

## GitHub Pages で公開する

1. このフォルダをリポジトリのルートとして push する
2. リポジトリの Settings → Pages を開く
3. Branch を `main`（または公開したいブランチ）、フォルダを `/ (root)` にする
4. 表示された URL を開く

`index.html` から相対パスで読み込むので、`https://ユーザー名.github.io/リポジトリ名/` でも動きます。

## ステージを足す

`js/stages.js` の `STAGES_SRC` にオブジェクトを追加します。セレクト画面とセーブデータは配列の長さに合わせて伸びます。

足場の数字 `y` は小さいほど高い位置です。地面は `408`。届きの目安はファイル先頭のコメントに書いてあります。
